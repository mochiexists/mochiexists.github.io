the fork

cmux Mochi

A public personal fork of cmux, the open-source agent terminal by Manaflow — carrying a small set of ergonomic additions for living inside agent-driven terminal work.

public source · personal builds

The source is public and the changes are documented, but this is not a product. Builds are signed and distributed for personal use and small-circle testing only — a macOS app updated from this fork's own release feed, and an iOS companion that lives on TestFlight by invitation. It is not intended for general distribution.

If you want cmux itself, get it from the source: the upstream project at cmux.com is the real thing, and everything here builds on it.

what changes

Resume-mode control, persistent scrollback, Codex close-and-resume, and other small sharpenings — the full tour is on the blog.

upstream

cmux is an open-source project by Manaflow. This fork tracks it closely and stays rebased on current releases.

source

The fork lives at mochiexists/cmux-mochi, same license as upstream.

privacy

What the personal builds do and don't send is written down plainly in the privacy policy.

cmux Mochi is unaffiliated with and unendorsed by Manaflow. The name cmux belongs to the upstream project; the Mochi belongs to Mochi.
